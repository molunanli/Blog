BIOS/UEFI 入门：怎么进、改什么、哪一步会变砖

✍️ 博主 📅 令和8年11月3日 ⏱ 阅读约 22 分钟
#电脑维修 #硬件 #Windows

装系统卡在第一步的人，多半卡在这儿：重启、猛按 Del、屏幕一闪而过进了 Windows。

或者进去了，面对一屏英文和一堆电压数字，不知道该碰哪个，索性全部 ESC 退出。

主板设置界面（BIOS / UEFI）是整台机器最底层的一层，也是最容易被神化的一层。有人说”别乱动，会烧主板”，也有人说”随便改，大不了清 CMOS”。两种说法都对一半。

这篇的目标很具体：让你知道该在什么时候进去、进去要改什么、以及哪一步真的会出事。至于超频调压那种事，本文不涉及——那属于另一个话题，而且不该在入门篇里教。

一、什么时候你会需要它

不是”了解知识”，是真会遇到。四种场景：

场景 你要做的事
装系统 / 重装系统 把 U 盘排到启动第一位（或用一次性启动菜单）
换了硬件不认（新硬盘、新显卡、新内存） 确认设备被识别、必要时改 CSM / Above 4G
内存跑不到标称频率 开 XMP / EXPO
系统进不去、蓝屏循环 改启动模式、关安全启动、恢复默认设置

外加一种”被动进入”：开机报错，比如 “Reboot and Select proper Boot device”、”CPU Fan Error”、CMOS 校验失败要你按 F1——这些都在把你往这个界面推。

※ 一句话定位主板设置界面管的是"开机之后、操作系统之前"那几秒钟的事：先找谁、按什么模式找、硬件按什么参数跑。Windows 里改不了的东西，基本都在这儿。

二、先分清：BIOS 和 UEFI 不是一个东西

日常说话混着用没关系，但你要动启动设置时，这个区别很关键。

传统 BIOS UEFI
年代 1981 年起，用了三十多年 2012 年后逐渐普及，现在全是它
分区表 MBR（最大 2TB、最多 4 个主分区） GPT（支持超大容量、128 个分区）
引导方式 读硬盘第一个扇区，找”活动分区” 直接读 EFI 分区里的 .efi 程序
界面 蓝底白字、只能用键盘 图形界面，支持鼠标
启动速度 慢（要逐个初始化硬件） 快（并行初始化）
安全启动 没有 有（Secure Boot）
现在叫什么 主板里的 CSM / Legacy 兼容模式 默认模式

关键的一句：现在的”BIOS 设置界面”其实已经是 UEFI 界面了，只是大家习惯还叫 BIOS。你在里面看到的 CSM、Legacy、Legacy+UEFI 选项，就是它模拟老 BIOS 的那部分。

图 1：两条链路各自完整、互不相通。混着用就是”找不到启动设备”。

⚠️ 这条最容易踩用 UEFI 模式装的系统，把启动模式改成 Legacy/CSM 之后，主板就看不见它了——不是系统坏了，是找的方法变了。反过来也一样。所以在改 `Boot Mode` 之前，先确认系统盘是 GPT 还是 MBR：磁盘管理 → 右键那块盘 → 属性 → 卷 → 看"分区样式"。

三、怎么进：三条路，按不上就换下一条

图 2：第一条最快但吃时机，第二条最稳但绕路，第三条最省事但有前提。

四、进去先别动：认清路再动手

不同厂商的界面差别很大，但结构是相似的：一个”简易模式”首页，加一个”高级模式”（通常按 F7 切换）。

你要找的东西，基本都在这几个位置：

想改什么 华硕 微星 技嘉 联想
启动顺序 Boot → Boot Option Settings → Boot BIOS → Boot Startup → Boot
XMP / EXPO Extreme Tweaker → XMP OC → A-XMP / XMP Tweaker → XMP 部分机型没有
安全启动 Boot → Secure Boot Settings → Security BIOS → Secure Boot Security → Secure Boot
虚拟化 Advanced → CPU → SVM/VT-x OC → CPU Features Advanced → SVM Security → Virtualization
恢复默认 F5 F6 F7 F9
保存退出 F10 F10 F10 F10
⚠️ 动手前的十秒钟进任何一项之前，先用手机把当前界面拍下来。改坏了两件事：一是不知道自己改了什么，二是不知道原来是什么值。这一张照片能省你半小时。

五、启动顺序：改得最多的一项

装系统、U 盘救援、双系统，都要改它。但这里有个几乎人人都踩过的坑：

5.1 两种”启动顺序”，别搞混

启动顺序（Boot Order） 一次性启动菜单（Boot Menu）
在哪 设置界面里的列表 开机按 F8/F11/F12/F9
效果 永久生效，以后都按这个顺序 只这一次，重启后恢复原样
适合 装完系统、长期固定 临时插个 U 盘救援，不想改设置
风险 改错了要再进来改回去 没有风险

日常推荐用一次性启动菜单——插上 U 盘、开机按 F12、选 U 盘、装完拔掉，什么都不用改回去。

六、XMP / EXPO：内存”标称频率”的真相

这是最容易被误解的一项。

你买了一条标着 DDR4-3200 的内存，插上去，任务管理器里显示 2133 或 2666。不是买到了假货，是它默认就跑这么慢。

原因是 JEDEC 标准规定了保守的默认频率（DDR4 常见 2133 / 2400 / 2666，DDR5 是 4800），保证任何平台插上都能亮。而 3200 这个数字，写在内存条里的一段预设配置中，需要你在主板设置里主动开启才会生效。

平台 这个功能叫什么
Intel XMP（Extreme Memory Profile）
AMD EXPO（EXtended Profiles for Overclocking）
华硕 AMD 平台 有时叫 DOCP，是同一件事的自家叫法

开的方法基本一样：找到 XMP / EXPO / DOCP，从 Disabled 改成 Profile 1，F10 保存。

6.1 开了会不会伤机器

说准确一点：

  • 这是内存厂商自己写好并验证过的配置，不是让你手动填时序电压，所以风险很低
  • 但它确实超出了 JEDEC 标准频率，严格意义上属于厂商背书的超频
  • 稳定性取决于 CPU 内存控制器的体质和插槽组合，同一个型号的内存，在 A 机器上稳，B 机器上可能不稳
  • 所以：开完先跑一遍压力测试（MemTest86 或 Windows 内存诊断），稳定再长期用

6.2 开了开不了机怎么办

多数主板有保护机制：连续几次自检失败会自动回退到默认频率。但也有不回退的，那就清 CMOS（第九节）。

💡 先想清楚要不要开日常办公、看视频、写代码，2133 和 3200 的差别你基本感觉不到。真正吃内存带宽的是游戏核显、视频渲染、大批量数据处理。 如果你的机器本来就稳，为了一个看不见的数字去冒"开不了机"的险，不划算。

七、安全启动与 TPM：Win11 的门槛，也是 BitLocker 的雷

这两个概念经常被绑在一起说，其实管的是两件事。

7.1 Secure Boot（安全启动）

它做的事很单纯：只允许”签名过”的引导程序运行。

  • 好处：拦住那些改写引导区的恶意程序（rootkit / bootkit）
  • 代价：没签名的系统装不上。装 Linux 双系统时如果撞上它，要么关掉，要么把发行版的密钥导入
  • 前提：必须是 UEFI 模式 + GPT 分区

7.2 TPM 2.0

一个专门存密钥的小芯片（或 CPU 里的固件实现：Intel 叫 PTT，AMD 叫 fTPM）。Windows 用它做磁盘加密、Windows Hello、凭据保护。

Win11 把它设成了硬性门槛——没有 TPM 2.0，官方渠道装不了。这也是为什么一堆老机器”明明还能用”却被挡在门外。

⚠️ 动这两个之前，先导出 BitLocker 恢复密钥如果系统盘开了 BitLocker（很多品牌机默认开），改 Secure Boot、清 TPM、刷 BIOS 都可能触发"恢复模式"，要求你输入一长串 48 位恢复密钥。找不到密钥 = 数据全丢，没有例外。

先查状态：管理员命令行跑 `manage-bde -status`。如果是"已开启"，立刻去导出：控制面板 → BitLocker 驱动器加密 → 备份恢复密钥（存到微软账户，同时截图/打印一份）。

这一步只要两分钟，但它是本文里唯一一个"不做就可能永久丢数据"的操作。

八、风险分级：哪些能改，哪些改了会出事

图 3：判断标准只有一条——改完开不了机，你能靠清 CMOS 救回来吗？

放心改（绿色）：启动顺序、XMP/EXPO、风扇曲线、虚拟化开关。这四项覆盖了普通人九成的需求，改错了最多恢复默认。

先备份再改（黄色）：Secure Boot、CSM/Legacy 模式、Above 4G Decoding、内存时序手调。这些改完可能直接开不了机，需要你会清 CMOS；而且 CSM 和 Secure Boot 还牵着已装好的系统能不能启动。

别碰（红色）：CPU 核心电压、内存电压、看不懂的 Advanced 子菜单、笔记本的隐藏菜单。这些不是”难”，是错了没有后悔药——电压给高了会烧供电，笔记本的隐藏菜单改错可能连清 CMOS 都救不回来（电池在主板背面）。

※ 一句话原则看不懂的选项，默认值就是最优解。厂商把默认值调到"能开机、能稳定跑"，不是为了坑你；你改它的收益，通常小于改坏它的风险。

九、改坏了怎么退：清 CMOS

这是所有”进不去系统”的兜底手段，也是你在第八节里敢动黄色档的底气。

9.1 先试最轻的：设置界面里恢复默认

还能进设置界面的话，直接 Load Optimized Defaults（华硕 F5 / 微星 F6 / 技嘉 F7 / 联想 F9），然后 F10 保存。

方法一（最通用）：断电 → 打开机箱 → 抠下主板上的纽扣电池（CR2032）

清完之后有三件事会变，别慌：

  1. 时间和日期会回到出厂值——联网后自动校准
  2. 启动顺序回到默认——如果你之前改过，要重新设
  3. XMP/EXPO 关闭——内存回到 2133/4800，需要重新开
⚠️ 清 CMOS 不是万能的它只重置"设置"，不修复"硬件"。如果改的是电压并且已经伤到供电，或者刷 BIOS 刷到一半断电，清 CMOS 是救不回来的——那是第十节的事。

十、刷 BIOS：三条红线

先说结论：绝大多数人一辈子不需要刷 BIOS。 它不是”更新一下更好”，而是”有明确理由才做”的手术。

10.1 什么情况下真该刷

  • 换上了新一代 CPU，老 BIOS 认不出来（这是最常见的正当理由）
  • 厂商明确说明修复了你正在遇到的 bug
  • 有公开的安全漏洞通告，且厂商发了补丁
  • 支持了新的硬件特性（比如更大容量的内存、新的接口）

“想试试新版本”不是理由。

10.2 三条红线

⚠️ 红线一：全程不能断电刷写过程中断电 = 大概率变砖。笔记本必须插着电源（电量 50% 以上），台式机最好接 UPS。别在雷雨天、别在电压不稳的老房子里刷。
⚠️ 红线二：型号必须完全一致不是"同系列"，不是"同芯片组"，是主板型号一字不差。华硕 B760M-K 和 B760M-A 是两个东西，刷错了轻则不认硬件，重则直接不亮。下载页面一定要从官网按型号进，别从论坛拿"通用版"。
※ 红线三：别跨大版本跳刷很多厂商要求逐版本升级（比如 1.0 → 1.2 → 1.5），中间不能跳。刷之前把官网的版本说明读一遍，它会写清楚"升级前需先刷到某版本"。

10.3 万一变砖了

还有三条路，按代价从低到高：

手段 适用 说明
BIOS Flashback 华硕、微星等部分型号 不用 CPU 和内存，把 BIOS 文件放 U 盘根目录、插指定 USB 口、按住按钮几秒
双 BIOS 切换 技嘉等部分型号 主 BIOS 坏了自动/手动切到备份 BIOS
编程器重刷 / 送修 都没有的情况 CH341A 类编程器夹 BIOS 芯片重写，或送售后

买主板时如果在意这个，Flashback 是个值得看一眼的功能——它把”刷 BIOS”从高风险动作降成了中风险。

十一、避坑 3 条 + 经验 3 条

⚠️ 避坑一：别在系统还能用时改启动模式觉得"UEFI 是不是比 Legacy 快"，就把 `Boot Mode` 从 UEFI 改成 Legacy——结果系统直接进不去。启动模式和已装系统的分区表是绑定的，要改就得重装，不能只改设置。
⚠️ 避坑二：改完一定要按 F10 保存不少人改完启动顺序，直接点右上角的 × 或按 Esc，界面关了，设置没存。下次开机一看全白干。F10 → 确认 Yes，这是唯一可靠的保存方式。
⚠️ 避坑三：别信"优化 BIOS 设置"的教程网上大量"关闭 C-State 提升性能""关掉节能让电脑更快"的帖子，多数是十年前的硬件语境，对现在的平台要么无效要么有害。没有具体问题，就不要做没有具体收益的改动。
💡 经验一：先拍照，再动手每一项改动前拍一张当前界面。改坏之后你至少有据可查，不用凭记忆猜"原来是 Auto 还是 Enabled"。
💡 经验二：一次只改一项和维修第一课的铁律一样。同时改了启动模式又关了安全启动又动了 XMP，结果开不了机——你不知道是哪一项干的。
💡 经验三：装系统前先把设置弄对装完系统再想改启动模式，等于要重装第二遍。装之前一次进去把：启动模式、安全启动、启动顺序都定好，能省一个晚上。

【排查】① 拔掉 U 盘重启 → 提示 "Reboot and Select proper Boot device"
      ② 进设置看启动模式：Legacy/CSM
      ③ 查磁盘分区样式：GPT
      ④ 判断：系统按 UEFI 装的（所以盘是 GPT），但主板启动模式是
         Legacy，两边对不上，主板找不到 EFI 分区
【结论】把 Boot Mode 改成 UEFI，保存重启 → 正常进入系统。
       → 教训：装系统前先确认启动模式，比装完再来救省事得多

两个案例对读：案例 A 说明大多数”改坏了”都能靠清 CMOS 救回来，所以不必谈 BIOS 色变；案例 B 说明设置和系统是配套的，装之前定好参数，比装完再调省一整晚。
