电脑维修手册：15 篇总目录 + 什么时候该送修

✍️ 博主 📅 令和8年11月4日 ⏱ 阅读约 12 分钟
#电脑维修 #Windows

这个栏目写了 15 篇，从按下电源键没反应，一路讲到误删之后怎么救数据。

但我一直觉得缺一样东西：一个入口。

15 篇文章按发布时间排下来，顺序是”我写的顺序”，不是”你用的顺序”。真出事的时候，没人会从第一篇开始读——你需要的是看症状，查表，点进去，照着做。

所以这一篇不是第 16 篇。它是前 15 篇的说明书。

一、三种读法，先选一条

同一堆文章，三种人是三种读法。先确认自己属于哪一种，能省掉大量翻页。

图 1：三条路不是三选一——C 里的两篇是 A 和 B 都会用到的兜底。

A 修好眼前这台。 电脑现在就坏着，你只需要那一篇。往下翻到第二节，按症状查。

B 系统学一遍。 没有具体故障，就是想搞懂”电脑到底怎么回事”。按编号从 #1 读到 #15，大约 9 小时。这个顺序是按依赖排的，不是按发布：先会看现象，再会定位，然后才动手。

C 只关心数据别丢。 三篇：#6 判断盘是不是在坏、#14 把备份做起来、#15 已经丢了怎么救。加起来一小时。如果你只打算读一次，读这条。

💡 关于"读了会不会过时"这 15 篇里的操作步骤跟着 Windows 10/11 走，通用逻辑（决策树、判断标准、边界条件）不会过时。版本变了以后，只有具体的菜单路径需要重新找一下——每篇里涉及路径的地方都写清了要打开哪个工具，照着找就行。

二、按症状查：一页搞定

这一节是整篇最该被收藏的部分。找最接近你症状的那一行。

你遇到的 先确认这三件事之一 去看
按电源键毫无反应，灯也不亮 插座有没有电 → 电源线/适配器 → 主板指示灯亮不亮 #1 第一课
风扇在转、灯在亮，屏幕全黑 外接一台显示器，有没有信号 #3 黑屏
卡在厂商 logo，进不去系统 能不能进 BIOS（连按 Del / F2） #3 黑屏 → #13 BIOS
提示”No bootable device” BIOS 里认不认得到硬盘 → 启动顺序对不对 #3 → #13 → #6 硬盘
蓝屏，能看到错误码 拍下来，或去 C:\Windows\Minidump 找文件 #4 蓝屏转储
蓝屏一闪就重启，看不到代码 先关掉”系统失败时自动重新启动” #4 蓝屏转储
用着用着自己重启 / 关机 烤机看温度 → 电源功率够不够 → 内存过不过测 #2 不定时重启
开机越来越慢，转圈要一分钟 启动项数量 → 硬盘是不是机械盘 / 快坏了 #5 七步体检 → #6
用着卡，风扇狂转，机身烫 任务管理器的 CPU 占用 → 核心温度 #7 散热 → #5
弹窗广告、主页被改、卸不掉 控制面板的安装时间排序 → 启动项 #9 流氓软件
系统更新完就蓝屏 / 黑屏 / 卡死 能不能进安全模式 #10 更新回滚
设备管理器一堆黄叹号、没声音没网 硬件 ID（devmgmt.msc → 属性 → 详细信息） #11 驱动
硬盘有咔咔声 / SMART 变黄 先备份，再看它还能撑多久 #6 硬盘 → #14 备份
想重装系统 备份做完了吗 → 启动盘做好了吗 #14 → #8 重装
想加内存 / 换固态，不知值不值 现在卡在哪一环（内存 / 磁盘 / CPU） #12 升级 → #13
误删了文件 / 格式化了盘 立刻停手，别再往这块盘写东西 #15 误删恢复
要进 BIOS 改设置 改哪一项是安全的、哪一项会变砖 #13 BIOS/UEFI

表里没有的？往回退一步，用下面这张分诊图。它的价值不在给答案，在帮你确认”我到底属于哪一类”——分错类，后面读什么都白读。

三、先分诊，再查表

图 2：三列的分界线是”系统有没有起来”，不是”看起来严不严重”。

有个反常识的地方：看起来最吓人的症状，往往最好修。

屏幕全黑、一声不响——可能是内存条没插紧，也可能是显示器线松了，拔插一次就好。而”能开机、能上网、就是偶尔卡一下”这种不痛不痒的毛病，反而可能指向硬盘快坏、内存出错，要花半天才能定位。

所以分诊不看”严重程度”，看能不能绕过系统：

  • 系统根本没起来（A 列）→ 问题在硬件或引导层，去看 #1 / #3 / #2
  • 系统起来了，但不正常（B 列）→ 问题在软件层，去看 #4 / #5 / #9 / #10 / #11
  • 系统正常，你只是不放心（C 列）→ 这是预防，去看 #6 / #7 / #12
⚠️ 一个例外要单独记住如果症状里带着"响"（硬盘咔咔声、电源吱吱声、风扇金属摩擦）或者"味"（焦糊味），别分诊了，直接断电。这一类属于硬件已经在自毁，每通电一分钟都在加重损伤，翻哪篇文章都没用。

四、自查 / 动手 / 送修：三条边界

这是这个栏目最开始就想讲清的一件事，但直到 15 篇写完才敢下定论：大多数”修坏了”不是技术不够，是越界了。

图 3：三格的边界不在”难不难”，在”坏得起不起”。

① 自查（不用工具，十分钟）：观察 + 记录 + 排除外设。拔掉所有 USB 设备再开机、换一根视频线、听声音、看指示灯颜色。绝大多数”电脑坏了”在这一步就被排除了——真的，先拔掉那个劣质 USB hub 试试。

② 动手（有备份、有工具、拆得回）：清灰换硅脂、换内存固态、重装系统、改 BIOS 设置。这一格的通行证是四条：拆得开记得住装得回、能进 BIOS 或 PE、重要数据已备份或可以放弃、弄坏了能接受。

③ 送修（别自己碰）：盘在响、有焦味、进过水、摔过压过、拆完多出螺丝、数据价值高于机器本身。这一格的正确动作是”断电、拍照、把故障描述写清楚”，不是”再试一个软件”。

📌 送修时最值钱的一句话把"我做过什么"讲清楚。修过哪里、装过什么、报错是什么时候开始的。维修师傅最怕的不是难修的机器，是被人动过又不说清动了哪里的机器——那等于把排查时间翻倍，而时间是要算钱的。

五、15 篇完整目录

按依赖顺序排，不是发布顺序。每篇给三样：讲什么、什么时候读、大概多久。

P0 现象排障线（#1~#7）：先让机器能用

# 篇目 讲什么 什么时候读 耗时
1 电脑维修第一课 不开机 / 蓝屏 / 卡顿三套排查思路；”先观测、后动手”的顺序 第一次遇到故障就读它，它是全系列的地基 12 分
2 不定时重启 / 关机 三步定位：温度、电源、内存；别一上来换电源 用着用着自己重启或关机 14 分
3 开机黑屏攻略 先分清”进不了 BIOS”和”进不了系统”，两条完全不同的路 屏幕没画面 16 分
4 蓝屏读转储 读 Minidump，精确到是哪个驱动；蓝屏不再靠拍照发帖 反复蓝屏 15 分
5 卡顿七步体检 重装之前的七步自检；先找出瓶颈再决定动不动手 越用越慢 18 分
6 硬盘告急 坏道、掉盘、SMART 三件事；判断还能不能用 有异响、SMART 报警、准备重装前 16 分
7 风扇与高温降频 清灰、换硅脂全流程；温度压不下去怎么办 风扇狂转、烫手、降频 20 分

P1 系统与软件线（#8~#11）：系统层面的活

# 篇目 讲什么 什么时候读 耗时
8 Windows 重装完全指南 做启动盘到装完设置；装前准备清单是重点 系统确实救不回来了 25 分
9 弹窗与流氓软件清理 安全模式清场 → Autoruns 揪根 → 防止复发 弹窗、主页被改、卸不掉 18 分

11 驱动那点事 该不该更新、去哪下、显卡驱动怎么卸干净；四个来源的优先级 黄叹号、没声音、花屏 20 分

14 数据备份 3-2-1 落地 三份副本两种介质一份异地；Windows 三件套；恢复演练 任何动手操作之前 20 分
15 误删 / 格式化恢复 停手优先于装工具；什么能救、什么别抱希望 已经删了 / 格了 22 分

六、三条依赖链：别跳着读

有几种读法会浪费时间，因为后一篇默认你已经读过前一篇。三条最常被跳错的：

重装链：#14 → #8 → #13。 想重装直接翻 #8 的人，八成会漏掉”装前准备”。而装完发现驱动装不上、系统认不到硬盘，就得回头补 #13 的 UEFI 与分区格式。先把数据搬走，再谈装。

黑屏链：#3 → #13 → #6。 黑屏最容易被误判成”显示器坏了”。#3 教你分清 BIOS 层和系统层；如果进得了 BIOS 但认不到硬盘，那就是 #13 的启动设置或 #6 的硬盘本身。

卡顿链：#5 → #6 → #12。 觉得慢就想升级？先做 #5 的七步体检找出瓶颈。瓶颈在硬盘，换固态；在内存，加内存；都不在，那 #12 会告诉你这台机器不值得再投钱。

💡 一条贯穿全系列的规矩动手之前先备份，这一条没有例外。15 篇里每一篇的操作章节都默认"数据已经安全"。没做到这一条，剩下的步骤都是在赌——而赌输的代价，正是第 15 篇讲的那种局面。

七、这 15 篇没讲什么

老实交代边界，比假装全面有用。以下这些不在这个栏目范围内，遇到了别在这里找答案：

没讲 为什么
macOS / Linux 排查逻辑相通，但命令与工具完全不同，硬套会出事
笔记本拆机细节 每个型号的卡扣、排线位置都不一样，看官方维护手册比看通用教程安全
主板级维修（换电容、补焊、量电压） 需要万用表和热风枪，属于电子维修而非电脑维修
开盘数据恢复 需要洁净间和专用设备，个人无法完成（#15 讲的是”什么时候该送去开盘”）
RAID / NAS / 服务器 场景偏向企业，容错逻辑与单机差别很大
手机、平板、打印机 各自独立，混在一起讲只会两边都不清楚
具体某款软件的用法 软件版本变化太快，写了半年就过期

一句话：这个栏目覆盖的是”一台普通的 Windows 电脑，一个人用，出了问题想自己弄明白”。 在这个范围内它够用；出了这个范围，我不装作能覆盖。

第一步 · 停（30 秒）
  有异响 / 焦味 / 进过水 → 断电，别开机，直接送修
  刚误删 / 刚格式化     → 停手，别装任何软件，看 #15
  其它                  → 继续

第二步 · 看（3 分钟）
  灯亮不亮？风扇转不转？屏幕有没有背光？
  能不能进 BIOS？（开机连按 Del / F2）
  最近装过什么、改过什么、摔过没有？

第三步 · 分类（对照第二节的表）
  系统没起来   → #1 / #3 / #2
  系统起来但不正常 → #4 / #5 / #9 / #10 / #11
  只是想预防   → #6 / #7 / #12

第四步 · 判断能不能动手
  拆得回吗？有备份吗？坏得起吗？能重装吗？
  四个都是"是" → 动手
  有一个"否"   → 送修（说清你做过什么）

第五步 · 动手前后各做一次
  动手前：备份（#14）
  动手后：跑验收（每篇末尾都有清单）

写在最后

15 篇写完，这个栏目就算交了。回头看，它其实只讲了一件事：

大多数电脑故障不是”坏了”，是”某个前提没满足”。 电源不够、散热不行、盘快坏了、驱动装错了、数据没备份。维修的动作往往很简单——清个灰、换根线、回滚一次更新——难的是判断该动哪里。

所以整个栏目的重心一直在判断上：决策树、判断矩阵、能力边界、什么时候该停手。具体的操作步骤反而写得克制，因为那些东西搜一下就有，而判断力搜不到。

如果这 15 篇只能留下一个结论，我希望是这个：

先备份，再折腾。 剩下的所有技巧，都是在这条之后才成立的。
