手把手：给博客做一张漫画风「创作热力图」

✍️ 博主 📅 令和8年9月3日 ⏱ 阅读约 12 分钟
#Hexo #CSS #JavaScript

给博客加”创作热力图”这件事，我前后折腾了四个版本。GitHub 贡献图大家都很熟——一串小色块，越绿说明那阵子越勤奋。别人的博客上有，我也想要一个。但直接照搬 GitHub 的绿色显然不对味：本站是日式漫画风，朱红是主题色。所以最终它长成了现在这样：12 张纸面月卡、朱红五级渐变、hover 时格子弹起来、附带会说话的漫画气泡。

这篇文章把整个创作思路捋一遍：风格怎么定、数据从哪来、布局踩过什么坑、交互怎么做的。文末附了一份不依赖任何框架、拷到本地就能跑的完整 HTML 示例，改几行假数据就能看到全部效果。

一、先定设计基调：抄思路，不抄配色

GitHub 的热力图是”青绿五级”（#ebedf0 → #196127）。我找过一份别人博客的热力图代码做参考——赛博朋克观测站风格，霓虹青配色、圆角格子、数字塞格、hover 放大。它交互做得确实好，逐条吸收：

  • 每个月份卡片带「一二三四五六日」星期头，周一起始
  • 格子内显示日期数字，hover 放大 1.4~1.5 倍
  • 今天的格子单独描边
  • 年份切换按钮有边界（下年不能超过今年）
  • 切换年份时统计数字跟着变

但配色和质感我全换了，换成和主题一致的语言：

投稿 我的选择 理由
级别色 朱红五级渐变：#f3d8c4 → #e8a878 → #d05a3a → #a13828 → #7a2820 主题强调色就是 vermilion
背景 纸面 --paper + 波点 呼应漫画网点纸
格子 2px 黑色硬边框 + 1px 偏移硬阴影 漫画线条的”描边”感，不是像素风那种圆润
今日标记 主题金色 --gold: #f2b829 和发文朱红区分开
气泡 黑边纸贴纸 + 45° 尖角 像漫画里的对话框旁注

一句话原则：**参考实现解决”交互细节”，主题变量决定”长什么样”**。

二、数据从哪来：让 Hexo 在构建时把日期聚合成 JSON

静态博客没有数据库，热力图的”发文记录”其实在构建那一刻就全部知道了——site.posts 里有每一篇的日期。所以思路是：构建时聚合，运行时只渲染。

做法是在归档页模板 archive.ejs 里用 EJS 遍历所有文章，按 YYYY-MM-DD 归并成计数对象：

// 在模板顶部（archive.ejs）做数据准备
var heatmapData = {};
var heatmapYears = [];
site.posts.each(function (p) {
    var d = p.date; // Hexo 的 moment 对象
    var key = d.format('YYYY-MM-DD');
    heatmapData[key] = (heatmapData[key] || 0) + 1;
    var y = d.year();
    if (heatmapYears.indexOf(y) === -1) heatmapYears.push(y);
});
heatmapYears.sort();
%>

<!-- 聚合结果直接以 JSON 形式嵌进页面，交给前端 JS -->
<script id="heatData" type="application/json"><%- JSON.stringify(heatmapData) %></script>
<script id="heatYears" type="application/json"><%- JSON.stringify(heatmapYears) %></script>

前端拿到的 data 大概长这样：

这样静态站不需要任何后端，数据天然随每次 hexo generate 更新。值得一提的是 type="application/json" 的 <script> 不会被执行，拿来当纯数据容器非常干净。

四、CSS：排布、着色、交互——以及我踩的坑

4.1 最大的坑：aspect-ratio: 1/1 让月份卡”越长越高”

这是我做过最”反直觉”的一次调试。第一版格子用了正方形约束：

csscss
1
2
3
.heat-cell {
    aspect-ratio: 1 / 1;  /* 格子高 = 格子宽 */
}

本来想的是”每个日期格子都是整齐的小方块”。结果在宽屏下，auto-fill 的流式布局排出了 7 列月卡，每张卡只有约 149px 宽——于是每格只有 16px 宽、16px 高，一个月 5~6 行日历硬生生把卡片撑到 340px 高。卡片长成了”细高条”（高/宽 ≈ 2.3），非常难看。而格子里的日期数字也被挤到放不下。

问题本质是：正方形的格子，宽度一旦被压缩，高度就会跟着膨胀。修法分两步：

  1. 行高固定，不再跟随宽度等比变化：.heat-month-grid { grid-auto-rows: 24px; }
  2. 显式 6 列布局，12 个月正好两排：.heat-grid { grid-template-columns: repeat(6, 1fr); }

改完实测：月份卡从 149×340 变成 175×197，整块热力图高度从 691px 缩到 461px，信息密度反而更高。教训：想让”日历矩阵”紧凑，应该控制行高而不是让宽高互相绑架。

4.2 等级色与”全部格子都能 hover”

配色用一个函数把篇数映射到级别，1 篇是浅橙，4 篇以上就是深朱红：

        color: #d7443e;
        font-weight: 800;

外面套一层 @media (hover: hover)，是让触摸设备直接跳过这些鼠标专属效果。

五、JS：把 12 个月渲染出来

核心是一个 monthHtml(year, month)：算出当月 1 号是星期几（周一为一周起点，所以周日要换算成偏移 6），前面补空位，后面补齐到整行，最后拼出星期头和日历：

var WEEK = ['一', '二', '三', '四', '五', '六', '日'];

function pad(n) { return n < 10 ? '0' + n : '' + n; }
function level(n) { return n <= 0 ? 0 : n === 1 ? 1 : n === 2 ? 2 : n === 3 ? 3 : 4; }

function monthHtml(y, m, data, todayStr) {
    var first = new Date(y, m, 1);
    var dow = first.getDay();               // 0 = 周日
    var offset = dow === 0 ? 6 : dow - 1;   // 周一对齐
    var days = new Date(y, m + 1, 0).getDate();
    var cells = '';

    for (var i = 0; i < offset; i++) cells += '<span class="heat-cell empty"></span>';
    for (var d = 1; d <= days; d++) {
        var key = y + '-' + pad(m + 1) + '-' + pad(d);
        var c = data[key] || 0;
        var today = key === todayStr ? ' heat-today' : '';
        var tip = (m + 1) + '月' + d + '日' + (c ? ' · 发文 ' + c + ' 篇' : '');
        cells += '<span class="heat-cell lv' + level(c) + today +
                 '" data-tip="' + tip + '">' + d + '</span>';
    }
    // 补尾部空位，凑成完整的 7 列行
    var rem = (offset + days) % 7;
    if (rem) for (var j = 0; j < 7 - rem; j++) cells += '<span class="heat-cell empty"></span>';

    var week = '<div class="heat-week">' +
               WEEK.map(function (w) { return '<span>' + w + '</span>'; }).join('') + '</div>';
    return '<div class="heat-month"><div class="heat-month-title">' +
           (m + 1) + '月</div>' + week +
           '<div class="heat-month-grid">' + cells + '</div></div>';
}

render(year) 把 12 个月拼起来塞进容器，同时更新统计行（”2026 年 · 共 1 篇 · 活跃 1 个月”）、处理年份边界（上年不可早于最早发文年、下年不可超过今年）、切换空年态。

渲染时机有个隐蔽的坑：内联脚本执行时 DOM 可能还没解析完，直接 render() 会扑空。稳妥做法是判断 document.readyState：

if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', function () { render(viewYear); });
} else {
    render(viewYear);
}

这个 bug 的真实惨状是：点任何按钮都正常、首次加载却一片空白——因为重构时把初次调用弄丢了，只剩点击事件里的 render。**交互逻辑改完，一定要先验证”首次加载路径”**。

六、值得收进清单的小细节

  • 颜色用主题变量：别在 JS/CSS 里散落十六进制，换主题时你会感谢自己。
  • 今天要能一眼找到：金边 + 呼吸动画，且和朱红的发文色系天然区分。
  • 空年不是 bug：跳到无文章年份给出明确空态，网格降权而不是消失。
  • 信息要可发现：所有日期格都可 hover 出气泡，不只是有文章的日子；cursor 用 help 暗示”这里有说明”。
  • 动效与无障碍：hover 效果包在 (hover: hover) 里；气泡文案同步进 aria-label；尊重 prefers-reduced-motion。

<script>
  // ============ 模拟数据：改成你自己的发文日期（YYYY-MM-DD） ============
  var POST_DATA = {
    '2026-01-12': 1, '2026-02-03': 2, '2026-02-28': 1, '2026-03-15': 1,
    '2026-04-08': 3, '2026-05-20': 1, '2026-06-01': 2, '2026-07-19': 1,
    '2026-08-31': 1, '2026-09-01': 2, '2026-09-03': 1
  };
  // =====================================================================

  var YEARS = Object.keys(POST_DATA).map(function (k) { return +k.slice(0, 4); });
  var MIN_Y = Math.min.apply(null, YEARS), MAX_Y = Math.max.apply(null, YEARS);
  var NOW = new Date();
  var THIS_YEAR = NOW.getFullYear();
  var TODAY = THIS_YEAR + '-' + pad(NOW.getMonth() + 1) + '-' + pad(NOW.getDate());

  var grid = document.getElementById('grid');
  var empty = document.getElementById('empty');
  var total = document.getElementById('total');
  var range = document.getElementById('range');
  var viewYear = THIS_YEAR;

  range.textContent = MIN_Y + ' ~ ' + MAX_Y + ' 年';
  var WEEK = ['一', '二', '三', '四', '五', '六', '日'];

  function pad(n) { return n < 10 ? '0' + n : '' + n; }
  function level(n) { return n <= 0 ? 0 : n === 1 ? 1 : n === 2 ? 2 : n === 3 ? 3 : 4; }
  function monthCount(y, m) {
    var sum = 0, p = y + '-' + pad(m + 1);
    for (var k in POST_DATA) if (k.indexOf(p) === 0) sum += POST_DATA[k];
    return sum;
  }
  function monthHtml(y, m) {
    var first = new Date(y, m, 1);
    var offset = first.getDay() === 0 ? 6 : first.getDay() - 1; // 周一起始
    var days = new Date(y, m + 1, 0).getDate();
    var cells = '';
    for (var i = 0; i < offset; i++) cells += '<span class="heat-cell empty"></span>';
    for (var d = 1; d <= days; d++) {
      var key = y + '-' + pad(m + 1) + '-' + pad(d);
      var c = POST_DATA[key] || 0;
      var isToday = key === TODAY ? ' heat-today' : '';
      var tip = (m + 1) + '月' + d + '日' +
                (c ? ' · 发文 ' + c + ' 篇' : '') + (isToday ? ' · 今天' : '');
      cells += '<span class="heat-cell lv' + level(c) + isToday +
               '" data-tip="' + tip + '" aria-label="' + tip + '">' + d + '</span>';
    }
    var rem = (offset + days) % 7;
    if (rem) for (var j = 0; j < 7 - rem; j++) cells += '<span class="heat-cell empty"></span>';
    var week = '<div class="heat-week">' + WEEK.map(function (w) { return '<span>' + w + '</span>'; }).join('') + '</div>';
    return '<div class="heat-month"><p class="heat-month-title">' + (m + 1) + '月</p>' + week +
           '<div class="heat-month-grid">' + cells + '</div></div>';
  }
  function render(y) {
    var html = '', sum = 0, active = 0;
    for (var m = 0; m < 12; m++) {
      html += monthHtml(y, m);
      var mc = monthCount(y, m);
      if (mc > 0) active++;
      sum += mc;
    }
    grid.innerHTML = html;
    grid.classList.toggle('is-empty', sum === 0);
    empty.classList.toggle('show', sum === 0);
    total.textContent = y + ' 年 · 共 ' + sum + ' 篇 · 活跃 ' + active + ' 个月';
    document.getElementById('prevBtn').disabled = y <= MIN_Y;
    document.getElementById('nextBtn').disabled = y >= THIS_YEAR;
    document.getElementById('thisBtn').style.background = y === THIS_YEAR ? '#f2b829' : '';
  }

  document.getElementById('prevBtn').onclick = function () { render(--viewYear); };
  document.getElementById('nextBtn').onclick = function () { render(++viewYear); };
  document.getElementById('thisBtn').onclick = function () { render(viewYear = THIS_YEAR); };
  document.getElementById('goBtn').onclick = function () {
    var v = parseInt(document.getElementById('yearInput').value, 10);
    if (v && v > 0) render(viewYear = v);
  };
  document.getElementById('yearInput').addEventListener('keydown', function (e) {
    if (e.key === 'Enter') document.getElementById('goBtn').click();
  });

  render(viewYear); // 注意：如果脚本放在 <head>，要等 DOMContentLoaded 再调
</script>
</body>
</html>

把这份文件里的 POST_DATA 换成你真实的发文日期（或者接到你自己的数据源），再按你站点的主题令牌调一遍颜色，就是完整版热力图了。数据、布局、交互三件事一旦想清楚，剩下的都是细节。

最后一个小结：做这类”数据可视化”小组件，我的顺序永远是——先定数据形状，再定视觉语言，然后才是像素细节。数据想清楚（构建期聚合 JSON），视觉有明确参照（抄交互思路 + 用自己的主题色），像素问题逐个击破（固定行高、伪元素气泡），最后的效果就不会差。希望你也能做出一张属于自己的热力图。
