风扇狂转与高温降频：清灰、换硅脂全流程，把温度压回去

✍️ 博主 📅 令和8年9月20日 ⏱ 阅读约 17 分钟
#电脑维修 #系统 #硬件 #散热

这是「电脑维修」系列的第六篇。上一篇体检到第 5 步时，我给过热降频留了一个”详见后续”，现在来兑现——这篇专讲风扇狂转与高温降频。

先厘清一个关键认知：风扇转得快不是故障，是它在拼命救火。真正的问题永远是”为什么这么烫”。所以看到风扇狂转，别急着换风扇，先问那句老话：热量是从哪儿来的、又卡在哪一环散不出去。

散热是一条四段链路：芯片发热 → 硅脂导热 → 散热器吸热 → 风扇+风道带走。这篇文章就按这条链路，带你定位到底哪一环出了问题。

图 1：四道关卡，任何一道堵住，热量都会在芯片里堆积，表现为温度升高、风扇狂转、最终降频变卡。

一、先分清”正常转”与”异常转”

风扇噪声是相对的。判断异常有个简单办法——对比两个时刻的噪音：

1. 刚开机、什么都不做时的风扇声（基准）
2. 打开一个较重的程序（游戏/渲染/多开网页）时的风扇声

正常：安静 → 明显变响，但属可接受的"工作声"
异常：一开机就狂转 / 满载时像吹风机 / 转速忽高忽低

还有个更客观的判据：温度。这就要请出本篇的核心工具。

1

下载 HWiNFO（免费，官网搜 HWiNFO 即可）→ 运行，选择「Sensors only」
重点看这几项：
· CPU Package / CPU (Tctl/Tdie) —— CPU 整体温度
· GPU Temperature —— 显卡温度（有独显时）
· CPU Fan / 各风扇 RPM —— 转速
· 以及 CPU 各项的「Core Clocks」—— 频率
💡 怎么用 HWiNFO 判断"降温"看两个场景：空闲温度（开机静置 5 分钟）和满载温度（打开重负载程序跑 10 分钟）。
• CPU 空闲 40~60℃、满载 70~85℃：健康
• 空闲就 70℃+：散热链路明显有问题（通常是硅脂或灰尘）
• 满载冲到 95~100℃：撞温度墙，CPU 主动降频——这就是"越玩越卡"的真凶
HWiNFO 还能勾选「CPU Core Clock」，降频发生时你会看到频率从 4.x GHz 掉到 2.x GHz，一目了然。

二、三步判断：到底堵在哪一环

拿到温度数据后，按下面三问定位。这张图就是完整的决策树：

图 2：三个问题定方向——温度不高只是吵，调风扇曲线即可；温度高再按热的时间点分流到灰尘、硅脂或风扇。

Q1：风扇是真狂转，还是你太敏感？
对比噪声基准，或看 HWiNFO 的 RPM 是否长期顶在高位。如果转速正常、温度也正常，那只是”敏感”，可以在 BIOS 或厂商控制软件里调一个更安静的风扇曲线，不用拆机。

Q2：温度是真的高吗？
用 HWiNFO 读数验证。温度不高就只是”吵”（同上）；温度高才进入 Q3。

Q3：什么时候热？这决定了修哪里。

现象 指向 走哪条路线
高负载才热，闲着没事 散热效率被拖累 路线 A：灰尘堵塞（最常见，先做）
开机就热、温度爬升极快，2~3 年没换过硅脂 硅脂干化失效 路线 B：换硅脂
转速忽高忽低、有咔咔异响、风扇时转时停 风扇本体故障 路线 C：换风扇
温度正常但偶尔卡死 不是散热问题 回看上一篇（内存 / 供电）
⚠️ 先清灰，再考虑换硅脂三条路线可能同时存在，但顺序不能乱：清灰零成本、十分钟搞定，先做；换硅脂要拆散热器、有风险，做完清灰如果温度还高再考虑。上来就换硅脂，很可能白拆一趟——灰才是最常见的原因。

三、动手前的准备（安全第一）

1. ★ 完全断电：关机 → 拔电源线 → 按住开机键 5 秒放掉余电
2. ★ 防静电：摸一下机箱金属框架/水龙头，或戴防静电手环
3. 工具：十字螺丝刀（磁性最好）、软毛刷（旧牙刷也行）、
       皮老虎/吹风机（冷风档）、无水酒精 + 无尘布/棉签、新硅脂
4. 拍照：拆之前先拍一张全景，螺丝位置和线材走向都拍下来
5. 容器：找个小盒子放螺丝，别让它滚进机箱
⚠️ 三条红线① 拆机前拔掉电源插头，不是只按关机——有些主板关机后仍有待机供电。② 绝对不要用吸尘器清机箱内部：吸尘器会摩擦产生静电，足以击穿主板元件，用皮老虎或吹风机冷风档。③ 笔记本在保就别自己拆——很多机型后盖螺丝上贴了保修贴，拆了就失保，先确认保修状态。

四、路线 A：清灰全流程（零成本，优先做）

灰尘是散热的头号杀手，也是最容易解决的一个。关键是找准该清的位置——很多人只擦了风扇叶片，结果温度毫无改善，因为真正堵死的是鳍片缝隙和出风口：

图 3：进风要通，出风更要通。清灰的三个必清位置按重要性排序：出风口与鳍片缝隙 > 风扇叶片 > 进风防尘网。

台式机清灰步骤：

1. 断电开侧板（通常后部两颗螺丝，向后抽拉）
2. 拆下 CPU 散热器的风扇（一般侧边卡扣或小螺丝固定）
   注意：先记住方向，别拔断风扇电源线
3. 清散热器鳍片：用软毛刷顺缝隙刷，配合皮老虎/冷风吹
   ★ 这一步最关键——鳍片被灰糊住，散热面积直接归零
4. 清风扇叶片：刷掉叶片正反面与根部的积灰
5. 清机箱防尘网、电源风扇（电源能吹到就吹，别拆电源）
6. 清机箱进出风口：后部排风扇、前部进风口的滤网
7. 装回风扇，插好电源线，合盖前检查没有螺丝遗留在机箱内

笔记本清灰（难度更高）：

1. 确认过保、且能拆后盖再动手
2. 拆后盖后，找到散热模组（一根或多根热管连着风扇）
3. 重点清：风扇出风口与鳍片连接处（灰尘常在这里结成"毛毡"）
4. 风扇叶片用软毛刷 + 冷风吹，别用嘴吹（口腔湿气会加速积灰）
5. 装回时确认所有排线接好（尤其风扇插头）

预期看到：清灰后满载温度下降 5~15℃（如果之前糊得很严重，下降会更明显）。如果几乎没变化，说明主因是硅脂或风扇，进入路线 B / C。

五、路线 B：换硅脂全流程（有一定风险，谨慎操作）

硅脂的作用是填补 CPU 顶盖与散热器底座之间的微观缝隙——金属表面再平整，显微镜下也是坑坑洼洼，空气是热的不良导体，硅脂就是来替补的。它用久了会干化、硬化、甚至开裂，导热能力大幅下降，于是”同样的负载，温度比以前高十几度”。

什么时候该换：

texttext
1
2
3
4
· 机器用了 2~3 年以上，从未换过散热硅脂
· 清灰后温度仍偏高（满载 90℃+）
· 出现"开机就热、升温极快"（图 2 里路线 B 的典型特征）
· 刚做过超频，或原本温度就吃紧

图 4：螺丝必须”对角交替、逐步松开”。顺序错了会让散热器一侧先失去压力，另一侧受力骤增，轻则变形，重则主板弯曲、针脚压弯，导致黑屏点不亮——不可逆损失。

1. 断电、放余电（重复第三节的准备动作）
2. 拆下散热器风扇（先拆风扇，再拆散热器本体，减少重量）
3. 按图 4 的顺序：对角交替，每次每颗螺丝只松半圈，
   轮流四遍，直到全部松动
4. 轻轻左右旋转散热器试探，如果粘住了（硅脂固化），
   先小幅度转动再抬起，不要垂直硬拔
5. ★ 抬起瞬间注意：AMD 平台（AM4/AM5）有时会把 CPU 连根拔起
   （俗称"拔萝卜"），原因是硅脂粘性太强
   → 防护：先让机器跑一会儿热一热再拆，或提前用酒精软化边缘
   → 一旦连根拔起，检查 CPU 针脚是否变形，别硬装
6. 分开后，用无水酒精 + 无尘布/棉签，把 CPU 顶盖和散热器底座上的
   旧硅脂彻底擦净，直到露出金属本色

图 5：硅脂只是”填补微观缝隙”，不是越厚越好。涂满整面会让多余硅脂被挤到主板与插槽上，厚层本身导热更差。

   （散热器底座较大的，可点"五点法"：中心一滴 + 四角各一小点）
2. 不要手动抹平！散热器压下去时会自然铺开
3. 装回散热器：同样按对角线交替顺序上螺丝，
   每次半圈轮流拧紧，保证受力均匀
4. 插回风扇电源线，先别合盖

2. 正常的话温度应明显低于换之前；进系统后用 HWiNFO 再测一轮
3. 跑 10 分钟重负载，确认温度比换硅脂前低 15~25℃

预期看到：温度下降 1525℃ 为正常。**只降了 23℃ 说明没涂好、没压紧，或旧硅脂没擦净（新旧混用效果打折）。**

六、路线 C：风扇故障的判断与更换

风扇是耗材，轴承磨损后转速会下降、抖动、发出异响，最终停转。

判断方法：

texttext
1
2
3
4
5
6
1. HWiNFO 看 RPM：风扇装好后转速应随温度上升而提高；
   如果温度升了转速不动，或读数忽有忽无 → 风扇/接口有问题
2. 断电后手动拨动扇叶：应该顺滑无阻力；
   如果发涩、卡顿、有颗粒感 → 轴承坏了
3. 摸机箱感受震动、听异响（咔咔声、摩擦声）
4. 观察叶片是否变形、断裂，或积了硬化的灰块

更换要点：

texttext
1
2
3
4
5
6
1. 记下原风扇的规格：尺寸（120mm / 92mm 等）、接口（3pin / 4pin）
   → 笔记本风扇通常是专用的整套模组，需按机型购买
2. 台式机机箱风扇可以直接换同规格的；CPU 风扇要匹配散热器型号
3. 注意出风方向：叶片上有箭头标示气流方向，别装反（装反等于没装）
4. 笔记本风扇模组更换需要一定动手能力，拆解步骤跟清灰类似，
   但要额外处理热管与散热片的连接

预期看到：新风扇转速正常、噪音消失，温度回到健康区间。

💡 风扇的"轴承类型"决定寿命普通含油轴承（Sleeve）寿命短、易漏油，1~2 年就可能异响；液压轴承（Hydraulic）/ 双滚珠轴承（Ball Bearing）寿命长得多。换风扇时如果价格差得不多，优先选后者——省得两年后再拆一次。这也是"便宜的风扇为什么一年就响"的答案。

七、别忘了环境与摆放：最容易被忽略的一环

温度高有时候不在机器里，而在机器外：

texttext
1
2
3
4
5
□ 机箱后部离墙 ≥ 10cm 了吗？（贴墙 = 热气排不走）
□ 是不是塞在封闭的电脑桌柜里？（最致命的摆放）
□ 笔记本是不是放在床上、抱枕上？（堵住底部进风口）
□ 环境温度是不是太高？（夏天没空调的房间，整体温度高 10℃）
□ 是不是灰尘特别大的环境？（那就缩短清灰周期到 3 个月）
💡 笔记本散热支架有用吗？有用，但作用是改善底部进风而不是"吹冷风降温"。带风扇的散热底座对进风口被挡住的机型提升明显（2~5℃），对本身就是侧进风的机型作用有限。相比之下，把它架高 2~3cm 让底部进气通畅，性价比最高——垫两个瓶盖都比闷在桌面上强。

八、验证与预防

怎么确认真的修好了：

texttext
1
2
3
4
1. 对比修前修后的 HWiNFO 温度读数（空闲 + 满载两组）
2. 满载温度应低于 85℃（CPU），且不再触发降频
3. 连续玩 1 小时原来会卡的游戏，帧数稳定、风扇声平稳
4. 观察几天：不再出现"用半小时后变慢"

预防清单：

  • 台式机每半年清一次灰，灰尘大的环境（临街、有宠物）缩到 3 个月
  • 笔记本每年清一次出风口，尤其是经常高负载使用的
  • 硅脂 3~5 年换一次（超频机器 2 年）
  • 机箱保持通风，后部留出排风空间，别放封闭柜里
  • 用 HWiNFO 每季度看一眼温度，发现基线抬升就及时清灰
  • 别长期把笔记本放在床上用——这不只是散热问题，长期高温还会加速电池老化

九、避坑与经验

⚠️ 六个坑，代价从几十到几千① 用吸尘器清机箱——静电可能击穿主板，这是最容易造成大损失的操作。② 按顺序依次拧螺丝——正确做法是对角交替逐步松开（图 4），否则主板/针脚可能受损。③ 硅脂涂太厚——以为"多涂点更好"，其实厚层导热更差，多余的还会溢出到插槽。④ 只擦风扇不擦鳍片——鳍片才是散热主战场，只擦叶片等于没清。⑤ AMD 平台垂直硬拔散热器——可能连 CPU 一起拔起并弄弯针脚，要先旋转再抬。⑥ 风扇装反——叶片上有方向箭头，装反等于白装。
💡 四条实战心得① 判断顺序永远是"先清灰 → 再看硅脂 → 最后换风扇"，成本从零到几十到上百，别跳步。② 拆机先拍照，螺丝按位置分开放——装回去时会感谢自己。③ 换硅脂后先开盖试机再合盖，万一温度没降下来，可以马上重来。④ 记下"健康基线温度"，以后每季度对比一次，温度抬升就是该清灰的信号，比等到发烫再处理主动得多。

       ③ 底座与顶盖上残留的旧硅脂形成了一层"干壳"，严重阻碍导热
【结论】无水酒精擦净旧硅脂 + 重涂（绿豆大小）+ 对角交替上紧
       → 满载温度 92℃ → 71℃。硅脂成本几块钱，效果立竿见影

两个案例对读：案例 A 是”灰”的问题，清灰就好，不必动硅脂；案例 B 是”硅脂”的问题，清灰没用，必须拆换。判断依据就是图 2 那个决策树——先清灰看效果，没改善再升级到换硅脂。
