欢迎使用 jp-blog 主题

✍️ 博主 📅 令和8年9月1日 ⏱ 阅读约 4 分钟
#Hexo #jp-blog #主题介绍

欢迎使用 jp-blog——一套日式漫画风格的 Hexo 主题。集中线、网点纸、对话框与和历日期，都是为了让技术博客少一点冰冷、多一点手感。

这篇文章会带你熟悉主题的目录结构、常用配置和写作方式，顺便把各种排版组件演示一遍。读完就可以删掉它，开始写你自己的第一篇了。

目录结构

主题文件都在 themes/jp-blog/ 下，你最常打交道的就这几个：

路径 用途
_config.yml 站名、导航、英雄区、作者卡、社交链接、页脚、404 文案
layout/ 页面模板：首页、文章页、归档、标签、分类、404
source/css/style.css 全部样式，配色集中在文件开头的 CSS 变量里
source/js/app.js 交互脚本：主题切换、搜索、目录高亮、代码块等

常用命令

bashbash
1
2
3
npx hexo server -p 4000    # 本地预览
npx hexo generate          # 生成静态文件
npx hexo new post "标题"    # 新建一篇文章
※ 提示改主题配置不用重启服务，刷新页面即可生效；改站点根目录的 `_config.yml` 则需要重启一次。

三步改成你的站

  1. 改站点信息：根目录 _config.yml 的 Site 段，填站名、副标题、作者。
  2. 改主题外观：themes/jp-blog/_config.yml，导航、英雄区标语、作者卡、社交链接、页脚都在这里。
  3. 换配色：source/css/style.css 顶部的 CSS 变量，改几个色值就能换一套皮。
💡 技巧侧边栏组件可以按需增删，配置项是主题 `_config.yml` 里的 `widgets`，目前支持 `profile`、`latest`、`tags`、`archive`、`subscribe` 五种。

brand: 我的博客
brand_seal: 博客
brand_note: 日式漫画风 · Hexo 主题

menu:
  首页: /
  归档: /archives
  标签: /tags
  关于: /about

hero:
  title: 欢迎来到我的博客！
  kicker: 日式漫画风 · 开箱即用
  speech: 这里写一句想对读者说的话。
  speech_small: — 开始你的第一篇 —
  update_freq: 不定期

profile:
  avatar: 🐱
  name: 博主
  role: BLOGGER

widgets:
  - profile
  - latest
  - tags
  - archive
  - subscribe

列表与引用

无序列表用来罗列要点：

  • 支持多级标题与目录自动生成
  • 支持有序列表、无序列表与任务列表
  • 段落、引用、表格、图片都用标准 Markdown 写

引用块用来强调一句话：

工具是服务于表达的。选顺手的那个，然后一直用下去。

下一步

💡 技巧跑熟之后，删掉这篇文章（`source/_posts/welcome.md`），再用 `npx hexo new post "标题"` 开一篇新的——你的博客就正式开张了。

如果遇到问题，先看看 hexo-docs/ 里的官方文档，或者打开浏览器控制台看看有没有脚本报错。祝你写得开心。
